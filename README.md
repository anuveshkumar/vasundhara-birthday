# Happy Birthday Vasundhara

Botanical birthday website with a separate hero image and a longer editorial scrapbook gallery.

- Main image: `images/hero.jpg`
- Gallery photos: `images/image01.jpg` through `images/image36.jpg`
- Hero crop, colors, layout and spacing: `style.css`
- Gallery text interludes and image count: `script.js`
- Birthday title and section markup: `index.html`

Edit the `notes` object in `script.js` to change the messages between photos.

Preview on Ubuntu:
```bash
python3 -m http.server 8000
```
Open http://localhost:8000.
